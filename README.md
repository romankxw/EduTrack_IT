> **Тема:** Online IT Courses Catalog (Каталог онлайн IT-курсів)

> **Дисципліна:** Веб-технології та веб-дизайн  

---

## 📌 Огляд проєкту

Проєкт є продовженням ЛР №1 (Figma-дизайн) та ЛР №2 (семантична HTML-розмітка). У цій роботі виконано візуальне оформлення сайту за допомогою препроцесора **Sass (SCSS)** за модульною архітектурою **7-1**, реалізовано мобільну верстку (mobile-first), адаптив на трьох ключових брейкпоінтах, систему міксинів, функцій та анімацій.

## 🏗 Архітектура стилів 7-1

Усі стилі розташовані в `src/scss/` і слідують архітектурному шаблону 7-1. Головний файл `main.scss` містить **виключно директиви `@use`**, без жодного CSS-правила всередині.

```
src/scss/

├── base/               # Базові правила оформлення
│   ├── _reset.scss     # Скидання стилів, доступність focus-visible, prefers-reduced-motion
│   ├── _typography.scss# Типографічна ієрархія (шрифт Inter, шкала h1-h3, body, caption)
│   ├── _utilities.scss # Utility-класи для spacing (.mt-*, .mb-*, .p-*) та visibility
│   ├── _print.scss     # Стилі для друку сторінок (приховування UI, вивід URL)

│   ├── _badge.scss     # Бейджі категорій
│   ├── _card.scss      # Картка курсу (.course-card) з aspect-ratio
│   ├── _input.scss     # Поля вводу, чекбокси, форми
│   ├── _search.scss    # Рядок пошуку курсів

│   ├── _nav.scss       # Десктопне меню, бургер та мобільне меню

│   ├── _details.scss   # Деталі курсу (статистика, програма, enroll-card)
│   ├── _enrollment.scss# Запис на курс (форма замовлення, order-card)
```

## 🎨 Дизайн-токени (Abstracts)

Токени імпортовані безпосередньо з дизайн-макета ЛР №1 (`01_Tokens.json`):
* **Кольори:**
  * `$color-surface`: `#f8fafc` (фоновий відтінок сторінки)
  * `$color-surface-alt`: `#ffffff` (поверхня карток та блоків)
  * `$color-text`: `#0f172a` (основний текст)
  * `$color-text-muted`: `#64748b` (допоміжний текст)
  * `$color-accent`: `#2563eb` (акцентний синій колір)
  * `$color-border`: `#e2e8f0` (лінії та межі)
  * `$color-rating`: `#f59e0b` (зірки рейтингу)
* **Типографіка:** Шрифт `Inter`, шкала від 13px (caption) до 40px (H1).
* **Брейкпоінти:**
  * `sm`: `360px` (мобільні пристрої)
  * `md`: `768px` (планшети)
  * `lg`: `1280px` (десктоп)
* **Відступи:** Шкала `$space` від 0 до 64px (`4px, 8px, 12px, 16px, 20px, 24px, 32px, 40px, 48px, 64px`).

> **Принцип чистоти:** У файлах `components/` та `layout/` відсутні літеральні HEX-коди чи магічні числа. Усі значення посилаються на змінні або функції `rem()`, `tint()` та `shade()`.

## ⚙️ Функції та міксини

### Функції (`_functions.scss`)
1. `rem($px)` — конвертує пікселі в значення `rem` відносно базового розміру (16px).
2. `tint($color, $amount)` — висвітлює колір змішуванням із білим (`color.mix`).
3. `shade($color, $amount)` — затемнює колір змішуванням із чорним (`color.mix`).

### Міксини (`_mixins.scss`)
1. `@mixin media-up($bp)` — реалізує підхід **Mobile First** (генерація `@media (min-width: ...)`).
2. `@mixin container($max)` — центрування контенту з адаптивними відступами-падінгами.
3. `@mixin flex($dir, $justify, $align, $gap)` — гнучке налаштування Flexbox.
4. `@mixin text-style($size, $lh, $weight)` — встановлення розміру, висоти рядка та жирності.
5. `@mixin transition($props...)` — плавні анімації переходів за стандартизованими часовими токенами `$duration` та кубічною кривою `$easing`.

### Бонус: Власний грід-міксин з gutters (12 балів)
Реалізовано набір міксинів для побудови довільних колоночних сіток:
* `@mixin row($gutter)` — флекс-контейнер із негативними відступами `margin-inline: -#{math.div($gutter, 2)}`.
* `@mixin col($span, $total: 12, $gutter)` — розрахунок ширини колонок у відсотках із збереженням gutter-падінгів.

## 🌟 Додатковий функціонал (10-12 балів)

1. **Utility-класи (`base/_utilities.scss`):**
   * Автоматична генерація класів відступів `.mt-0` ... `.mt-16`, `.mb-*`, `.p-*` через директиву циклу `@each`.
   * Класи доступності `.visually-hidden` та приховування `.is-hidden`.
2. **Print-стилі (`base/_print.scss`):**
   * Автоматичне приховування навігації, хедера, футера, фільтрів та пагінації при друку.
   * Виведення повних URL-адрес зовнішніх посилань: `a[href^="http"]::after { content: " (" attr(href) ")"; }`.
   * Запобігання розриву карток при розбитті на сторінки: `break-inside: avoid`.
3. **Система анімацій (`base/_animations.scss`):**
   * Keyframes `fade-in` та `slide-up`.
   * Анімуються виключно апаратні властивості: `opacity` та `transform` (без затримки рендерингу).
   * Клас плавного завантаження `.is-appearing`.
4. **Доступність та фокус:**
   * Стан `:focus-visible` обов'язково збережений з чітким контуром для навігації з клавіатури.
   * Медіазапит `(prefers-reduced-motion: reduce)` вимикає анімації для користувачів із чутливістю до руху.

## 🚀 Запуск проєкту

### 1. Запуск у режимі розробки:
```bash
npm run dev
```
Відкрити [http://localhost:5173/](http://localhost:5173/) у браузері.

### 2. Перевірка лінтером SCSS (Stylelint):
```bash
npm run lint:css
```
Використовується суворий стандартний конфіг `stylelint-config-standard-scss` та плагін `stylelint-order`. Усі правила проходять без помилок.

### 3. Продакшн-збірка:
```bash
npm run build
```
Зібрані оптимізовані файли розміщуються у директорії `dist/`.
