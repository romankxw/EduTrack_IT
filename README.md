# EduTrack IT — Онлайн-каталог IT-курсів

> **Навчальний проєкт з дисципліни:** «Веб-технології та веб-дизайн»  
> **Тема проєкту:** Online IT Courses Catalog (Варіант 5)  
> **Студент:** Комарницький Роман  
> **Поточний стан:** Реалізовано ЛР №1 (Figma-дизайн), ЛР №2 (HTML-семантика та структура), ЛР №3 (SCSS, адаптив, архітектура 7-1), ЛР №4 (JS-інтерактивність, REST API json-server, класи, кеш, оптимістичний UI)  

---

## 📌 Огляд проєкту

**EduTrack IT** — це наскрізний веб-проєкт сучасного каталогу акредитованих онлайн-курсів у сфері інформаційних технологій (Frontend, Backend, AI/ML, Cloud/DevOps). Проєкт поетапно розробляється протягом семестру з поступовим нарощуванням складності: від дизайн-системи у Figma до семантичної верстки, SCSS-архітектури, адаптивності та клієнтської інтерактивності.

### Стек технологій
* **Збирач та інструменти:** [Vite](https://vitejs.dev/)
* **Шаблонізація:** [EJS](https://ejs.co/) (`vite-plugin-ejs`)
* **Розмітка та семантика:** HTML5, Schema.org (JSON-LD), ARIA Landmark Roles
* **Стилізація:** Sass/SCSS (модульна архітектура 7-1, методологія BEM, Mobile First)
* **Якість коду:** [Stylelint](https://stylelint.io/) (`stylelint-config-standard-scss`, `stylelint-order`)
* **Клієнтський скрипт:** Vanilla JavaScript (ES6+ модулі, клавіатурна доступність)

## 🧭 Структура сторінок проєкту

Сайт складається з 4 повноцінних ключових сторінок:

1. **`index.html` (Головна сторінка — Home):**
   * **Hero-секція:** привабливий банер з арт-дирекшн зображенням (narrow для мобільних, wide для десктопу) та головним закликом до дії (CTA «Explore Courses»).
   * **Featured Programs:** динамічно згенерована сітка рекомендованих курсів (перші 3 картки) на базі EJS-шаблону.
2. **`courses.html` (Каталог курсів — Courses):**
   * **Фільтри курсів:** сайдбар із групами фільтрації за напрямом (Domain) та рівнем підготовки (Experience Level).
   * **Мобільні кнопки керування:** на мобільних пристроях сайдбар замінюється інтерактивними кнопками `[ ⚙ Filters ]` (висувна панель фільтрів із живим підрахунком активних параметрів) та `[ ⇅ Sort ]` (мобільне меню вибору критерію сортування).
   * **Компактна пагінація:** адаптивне віконне відображення номерів сторінок (`generatePages` з еліпсисом `...`), яке повністю вміщується на будь-якому мобільному екрані від 360px без горизонтального скролу.
   * **Пошукова панель та лічильник:** інтегровані безпосередньо над каталогом з лічильником кількості курсів.
   * **Сітка курсів:** адаптивний каталог (1 колонка на мобільних, 2 на десктопі).
3. **`course-details.html` (Сторінка курсу — Course Details):**
   * **Хлібні крихти (Breadcrumbs):** ієрархічна навігація `Home / Courses / Course Details` (приховується на мобільних для економії простору).
   * **Картка показників курсу (Course Stats):** адаптивна сітка з 4 окремих карток з ключовими даними (Duration: 12 Weeks, Level: Intermediate, Rating: ★ 4.9, Language: English).
   * **Опис та результати навчання:** просторий, комфортний для читання текст (About, What you'll learn) із маркованими списками.
   * **Навчальна програма (Curriculum):** потижневі компактні картки модулів із симетричними відступами.
   * **Сайдбар запису (Enroll Card):** закріплена (sticky) картка з актуальною ціною `$199`, перекресленою знижкою `$299`, кнопкою швидкого запису, блоком переваг «Course Features» із галочками та гарантією повернення коштів.
4. **`enrollment.html` (Форма запису — Enrollment Application):**
   * **Центрована картка оформлення:** акуратний макет на 640px, що повністю відповідає Figma-дизайну.
   * **Прев'ю-банер курсу:** плашка з назвою вибраного курсу, розкладом та ціною.
   * **Структурована форма:** логічно розбиті блоки `fieldset` (особисті дані, створення акаунту, платіжні дані, згода з правилами сервісу) з клієнтською HTML5-валідацією та підказками доступності.
5. **`auth.html` (Вхід та реєстрація — Sign In & Register):**
   * **Доступний таб-перемикач:** миттєве перемикання між формою входу та реєстрації нового студента (`role="tab"`, `aria-selected`, `aria-controls`).
   * **Клієнтська валідація:** Constraint Validation API з перевіркою формату email, мінімальної довжини пароля (8 символів), імені та згоди з правилами.
   * **Доступні статуси:** живі сповіщення про успішний вхід або створення акаунту через `role="status"`.

## 📦 Результати ЛР №2: HTML-семантика, структура та доступність

У межах 2-ї лабораторної роботи було створено фундамент проєкту:

* **Модульна архітектура шаблонів (EJS):**
  * Повторювані компоненти винесено в `src/partials/`:
    * `header.ejs` — шапка з доступним логотипом, головною навігацією, кнопкою входу та мобільним бургером.
    * `footer.ejs` — підвал з копірайтом.
    * `course-card.ejs` — уніфікована карточка курсу з підтримкою динамічних параметрів.
  * Усі дані про курси спочатку зберігалися у `src/data/courses.json`, а в межах ЛР №4 повністю мігровані в `db.json` (32 курси з повними зв'язками для `json-server`).
* **Семантична повнота HTML5:**
  * Використано виключно семантичні контейнери: `<header>`, `<nav>`, `<main id="main">`, `<article>`, `<aside>`, `<section>`, `<footer>`, `<figure>`, `<picture>`.
  * **Жодних інлайнових стилів (`style="..."`)** у розмітці.
* **Доступність (Accessibility / a11y):**
  * Повна підтримка скрінрідерів за допомогою ARIA-атрибутів: `aria-label`, `aria-labelledby`, `aria-expanded`, `aria-controls`, `aria-current="page"`, `aria-required`, `role="list"`, `role="alert"`.
  * Реалізовано цільовий якір для швидкого переходу до основного контенту (`<main id="main">`).
  * Збережено й акцентовано видимий контур фокусу `:focus-visible` для клавіатурної навігації.
* **Семантичні мікродані (Schema.org / SEO):**
  * Впроваджено структуровані дані у форматі **JSON-LD**:
    * На головній сторінці — розмітка типу `WebSite` з описом та `SearchAction`.
    * На сторінці курсу — розмітка типу `Course` із зазначенням провайдера (`Organization`), тривалості (`timeRequired`), ціни (`Offer`) та відгуків (`AggregateRating`).
* **Адаптивні зображення (Responsive Images):**
  * Усі ілюстрації та обкладинки підготовлені у сучасному форматі **WebP** з резервним фолбеком у **JPEG**.
  * Використано `<picture>`, `<source>` та атрибути `srcset` з дескрипторами ширини (`380w`, `640w`, `1280w`) разом із медіа-правилами `sizes`.
  * Запобігання Cumulative Layout Shift (CLS) завдяки атрибутам `width`/`height` та фіксації пропорцій.
* **Доступне мобільне меню (`src/js/nav.js`):**
  * Легкий скрипт на чистому Vanilla JS без сторонніх бібліотек.
  * Керує атрибутами `aria-expanded` та `hidden`, підтримує швидке закриття меню клавішею `Escape` з поверненням фокусу на кнопку-бургер.

## 🎨 Результати ЛР №3: SCSS, адаптив, архітектура 7-1

У 3-й лабораторній роботі реалізовано повне візуальне оформлення відповідно до дизайн-системи з Figma:

### 1. Модульна архітектура 7-1 (`src/scss/`)
Стилі проєкту строго розділені за ролями, а головний файл `main.scss` містить **виключно директиви `@use`**:

```
src/scss/
├── abstracts/          # Змінні, функції, міксини (не генерують CSS без виклику)
│   ├── _variables.scss # Токени: кольори, шрифти, брейкпоінти (sm, md, lg), spacing-шкала
│   ├── _functions.scss # Функції: rem(), tint(), shade() на базі sass:math та sass:color
│   ├── _mixins.scss    # Міксини: media-up(), container(), flex(), text-style(), transition(), row(), col()
│   └── _index.scss     # Експорт через @forward

│   ├── _typography.scss# Типографічна шкала h1-h3, комфортні інтерліньяжі для body та caption

│   └── _index.scss

│   ├── _badge.scss     # Бейджі категорій

│   ├── _header.scss    # Шапка сайту з відступами container та фірмовим синім логотипом
│   ├── _footer.scss    # Підвал сайту
│   ├── _nav.scss       # Десктопна навігація, бургер та мобільне меню
│   ├── _grid.scss      # Адаптивні сітки сторінок та бонусний колоночний грід
│   └── _index.scss
├── pages/              # Стилі конкретних сторінок
│   ├── _home.scss      # Головна (Hero-секція, CTA на всю ширину для mobile)
│   ├── _courses.scss   # Каталог (компактний пошук у сітці, мобільні кнопки Filters/Sort)

│   └── _index.scss
```

### 2. Дизайн-токени (Abstracts)
* Усі стилістичні константи перенесені з макетів Figma (`01_Tokens.json`, `02_Components.json`):
  * **Кольори:** `$color-surface: #f8fafc`, `$color-surface-alt: #ffffff`, `$color-text: #0f172a`, `$color-text-muted: #64748b`, `$color-accent: #2563eb`, `$color-border: #e2e8f0`.
  * **Шрифт:** сімейство `Inter`, система вагів 400/500/600/700.
  * **Брейкпоінти (Mobile First):** `sm: 360px` (мобільні), `md: 768px` (планшети), `lg: 1280px` (десктоп).
  * **Відступи:** шкала `$space` від 0 до 64px.
* **Принцип чистоти коду:** у файлах компонентів відсутні магічні числа та "сирі" HEX-коди.

### 3. Функції та міксини
* `rem($px)` — надійна конвертація пікселів у відносні `rem`.
* `tint($color, $amount)` та `shade($color, $amount)` — висвітлення/затемнення кольорів без генерації жорстких дублікатів палітри.
* `@mixin media-up($bp)` — чистий Mobile First підхід через `min-width`.
* `@mixin container($max)` — адаптивний центрувальний контейнер із безпечними gutter-відступами.
* `@mixin flex()` та `@mixin text-style()` — семантичні шорткати.
* **Бонус (на 12 балів):** кастомний грід-міксин `@mixin row($gutter)` та `@mixin col($span, $total: 12, $gutter)` з відсотковим розрахунком колонок і компенсацією gutters.

### 4. Додаткові можливості
* **Utility-класи (`_utilities.scss`):** автоматична генерація класів відступів `.mt-0` ... `.mt-16`, `.mb-*`, `.p-*` через цикл `@each`, класи приховування `.is-hidden` та доступності `.visually-hidden`.
* **Print-стилі (`_print.scss`):** оптимізація друку сторінок (приховування навігації й кнопок, розкриття URL зовнішніх посилань через `attr(href)`, `break-inside: avoid` для карток).
* **Система анімацій (`_animations.scss`):** keyframes `fade-in`, `slide-up` та клас `.is-appearing`, які анімують виключно апаратно оптимізовані властивості (`opacity` та `transform`), не перевантажуючи CPU/GPU.

## ⚡ Результати ЛР №4: JS-інтерактивність та API (json-server)

У 4-й лабораторній роботі реалізовано повний цикл клієнтської логіки на чистому JavaScript (ES-модулі, сувора класова організація, без UI-фреймворків) із взаємодією через REST API локального `json-server`. Реалізовано всі вимоги на **максимальні 12 балів**:

### 1. Архітектура класів (`src/`)
* **`HttpClient` (`src/api/http.js`):**
  * Інкапсулює мережеву взаємодію на базі `axios` (baseURL `http://localhost:3001`, timeout `8000ms`).
  * Нормалізує помилки (`HttpClient.normalize`), перехоплює HTTP-статуси та таймаути.
* **`RequestCache` (`src/api/cache.js`):**
  * Кешування HTTP GET відповідей з TTL (60 000 мс).
  * Автоматична інвалідація (очищення) кешу при мутаціях (POST/PATCH).
* **`ItemService` (`src/services/ItemService.js`):**
  * Предметна логіка курсів: `getList({ q, level, domain, sort, order, page, limit })`, `getById(id)`, `setLikes(id, likes)`, `createEnrollment(data)`.
  * Читання заголовка `X-Total-Count` для точного розрахунку сторінок пагінації.
* **`ListView` (`src/views/ListView.js`):**
  * DOM-рендер списку курсів, скелетон-карток під час завантаження (`renderLoading`), стану порожнього пошуку (`renderEmpty`) та блоку помилки з кнопкою повтору (`renderError` + `Retry`).
* **`Paginator` (`src/components/Paginator.js`):**
  * Серверна пагінація: розрахунок кількості сторінок за `X-Total-Count`, коректне блокування кнопок `Prev`/`Next`, стан `aria-current="page"`.
* **`FormView` (`src/views/FormView.js`):**
  * Клієнтська валідація форми замовлення через Constraint Validation API (`novalidate`, `checkValidity()`, кастомні повідомлення).
  * Фокус на першому невалідному полі, прив'язка підказок через `aria-describedby` та позначення `aria-invalid="true"`.
  * Автозбереження чернетки у `localStorage` на кожне введення (`draft:enrollment`) та її відновлення при оновленні сторінки.
  * Відправка `POST /enrollments` у `json-server`, очищення чернетки після успіху, вивід доступного статусу `role="status"`.
* **`DetailsView` (`src/views/DetailsView.js`):**
  * Динамічний рендеринг сторінки конкретного курсу за ID (`getById`).
* **`HashRouter` (`src/router/HashRouter.js`):**
  * Власний легкий hash-роутер без сторонніх бібліотек для обробки `#courses` / `#/list`, `#/item/:id` та невідомих шляхів (404).
* **`queryState` (`src/utils/queryState.js`):**
  * Джерело істини списку — URL (`URLSearchParams` + `history.pushState` / `replaceState`).
  * Підтримка навігації кнопками браузера "Назад/Вперед" (`popstate`).

### 2. Функціональні можливості каталогу (`courses.html`)
* **Пошук із Debounce (300 мс):** жива фільтрація назв курсів без спаму запитами до API.
* **Фільтрація та сортування:** вибір напряму (Frontend, Backend, AI/ML, DevOps, Security), рівня підготовки (Beginner, Intermediate, Advanced) та сортування (за новизною, ціною, рейтингом).
* **Скидання пагінації:** будь-яка зміна фільтра чи пошуку скидає номер сторінки на `1`.
* **Бонус (на 12 балів) — Оптимістичні лайки з відкатом:**
  * Клік на сердечко `♥` на картці курсу миттєво збільшує лічильник в UI, блокує кнопку.
  * У фоні відправляється `PATCH /courses/:id` та інвалідується кеш.
  * У разі помилки або зупинки сервера лічильник **миттєво повертається назад** (відкат), а користувачеві виводиться зрозуміле повідомлення.

### 3. Структура `db.json`
Файл бази даних містить 5 колекцій:
* `courses` — **32 повноцінні курси** (із полями `id`, `title`, `slug`, `domain`, `category`, `level`, `price`, `rating`, `reviews`, `likes`, `publishedAt`, `imagePrefix`, `summary`, `tags`).
* `instructors` — 6 провідних викладачів.
* `categories` — 5 категорій курсів.
* `reviews` — відгуки студентів.
* `enrollments` — порожній масив під записи з форми оформлення.

## 🛠 Інструкція з розгортання та запуску

### 1. Встановлення залежностей
```bash
npm install
```

### 2. Одночасний запуск API та клієнта (Рекомендовано)
```bash
npm start
```
Команда запускає паралельно:
* `json-server` (REST API) за адресою [http://localhost:3001/](http://localhost:3001/) з емуляцією затримки мережі `--delay 300`
* `Vite dev server` за адресою [http://localhost:5173/](http://localhost:5173/)

### 3. Окремий запуск сервісів
* **Тільки REST API (json-server):**
  ```bash
  npm run api
  ```
* **Тільки фронтенд (Vite):**
  ```bash
  npm run dev
  ```

### 4. Перевірка якості коду (Лінтинг)
* **JavaScript (ESLint):**
  ```bash
  npm run lint
  ```
  Помилок лінтера: **0**.
* **Стилі SCSS (Stylelint):**
  ```bash
  npm run lint:css
  ```
  Помилок стилів: **0**.

### 5. Збірка проєкту для продакшену (Build)
```bash
npm run build
```
Скомпілює оптимізовані HTML, мініфіковані CSS та JS бандли в директорію `dist/`.

### 6. Попередній перегляд зібраного проєкту (Preview)
```bash
npm run preview
```

### 7. Деплой та Live Preview (GitHub Pages)

Проєкт підготовлено до автоматичного деплою на **GitHub Pages** за допомогою сучасного CI/CD пайплайну GitHub Actions (`.github/workflows/deploy.yml`).

#### Дворежимна архітектура (Hybrid API / Static Demo):
1. **Повний локальний режим (`npm start`):**
   * Запускає справжній `json-server` (порт 3001) із базою `db.json`, що обробляє повноцінні HTTP-запити (`GET`, `POST /enrollments`, `PATCH /courses/:id`), емулює затримку мережі 300мс і повертає заголовок `X-Total-Count`.
   * **Демонстрація відкату оптимістичного UI:** при вимкненому `json-server` клік по лайку миттєво повертає лічильник назад і показує сповіщення про помилку.
2. **Онлайн Live Preview (статичний хостинг):**
   * Оскільки статичні сервери (GitHub Pages) не виконують постійні фонові процеси Node.js, `ItemService` прозоро активує вбудований статичний фолбек (`public/db.json`).
   * Завдяки цьому користувач у живому браузерному демо може:
     * переглядати весь каталог із **32 реальних курсів**;
     * застосовувати комбіновані фільтри за категоріями та рівнями;
     * користуватися суворим токенним пошуком із межами слів (запит `AI` повертає виключно курси ШІ);
     * перемикати сторінки та переходити до сторінок деталей курсів і форми запису.
